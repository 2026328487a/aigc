# 从视频提取声音克隆参考录音

在工作台选择 **VoxCPM2 → 声音克隆**，展开 **从视频提取／裁剪参考录音**。

1. 选择本机视频或录音，支持 MP4、MOV、MKV、WAV、MP3 等解码库可识别的格式，文件上限 128 MB。
2. 播放源文件定位，填写开始和结束秒数，选取 3–30 秒。也可点击“从当前播放位置开始”。30 秒以内的源文件默认选取全部，较长文件默认选取前 15 秒。
3. 按需勾选“裁去首尾静音”。只裁剪所选范围的两端，保留中间停顿；这不是降噪或人声分离。
4. 点击“提取并用作参考录音”。完成后在下方试听；结果已自动选为克隆参考，不需要下载后重新上传。也可点击“下载参考 WAV”保存。
5. 填写待朗读文字，连接 DGX 后开始声音克隆。“录音原文”如填写，需与最终选取的录音内容一致。

提取在本机进行，无需 DGX。输出为单声道、24 kHz、16 位 PCM WAV，不包含源文件元数据。源视频仅用于本地提取；提交克隆任务时上传的是处理后的 WAV。提取结果不会单独写入工作台历史；刷新页面前可下载保存，提交克隆后参考音频随该任务存入本地历史。

选择新源文件或修改时间／静音选项后，需要重新提取，以免使用旧片段。浏览器无法预览某种编码时，仍可手动填写时间并尝试提取。无音轨、损坏文件、实际音频不足 3 秒，以及静音裁剪后不足 3 秒，都会显示具体提示。多音轨文件默认使用第一条音轨。

## 实现与验证（2026-10-17）

- 复用现有 PyAV 及其 FFmpeg 库，无需安装额外程序；`POST /api/reference-audio/extract` 在后台线程解码所选范围并返回 WAV。
- 首尾静音以 -40 dBFS 为阈值，保留约 250 毫秒边缘余量，不修改音色或音量。
- `python -m unittest discover -s tests -v`：37 项通过，包括格式转换、精确选段、MP4 音轨、静音处理、无音轨、过短／过长范围、损坏文件与大小限制。
- `python scripts/reference_ui_smoke.py path/to/video.mp4`：在隔离服务中运行真实 Edge 检查，提取、播放、下载、参考录音提交及错误恢复通过；390px 宽度无横向溢出。下载的 WAV 与独立接口提取结果一致，克隆任务保存的参考 WAV 与下载内容一致。
- 实测输入视频约 11.52 秒；完整音轨约 11.48 秒，裁去首尾静音后约 7.91 秒。浏览器测试仅替代了远端合成 worker，没有调用实际语音生成。
