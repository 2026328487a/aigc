## 已修复并验证的问题

- 修脸节点的模型路径与枚举值不同于原下载工作流，已按 DGX 实际节点接口调整，并成功生成样片。
- 短录音数字人原先可能在录音结束后继续生成声音。现在由录音长度决定画面张数，成片直接使用对应输入音轨；约 3.04 秒的录音已生成约 3.04 秒的视频。
- 人物参考文件需要独立保存和上传入口。现在结果会归档到本机，复用模板提供“上传参考素材”按钮；重新连接后的复用已跑通。
- 归档器先查历史、再查队列时，可能跨过任务完成的瞬间，把成功任务误判为取消。现在队列中没有任务时会再次查询历史，并为尚未出现的结果留出等待时间；相关自动测试通过，换头样片补跑后成功保存。
- API 工作流画布原先排成一长列。现在按前后依赖横向排列，并等待 ComfyUI 初始化完成、核对加载节点后再提示成功；最终逐模板界面验收仍待完成。

## 效果方面已经发现的限制

- 续镜样片只验证了两段，接缝附近未见明显跳脸；这不足以证明更长的视频会一直稳定。
- 换人样片使用单人素材时，参考图中的服装能够迁移。多人、遮挡和快动作未系统验收。
- 换头使用全身参考图时可能连服装一起改变，所以补跑改用只含头部的参考图；人物相似度、侧脸与动作保持程度仍需继续看成片比较。
- 数字人采用输入音轨，不表示嘴型已经精确同步；还需要观看与听音检查。
- 人物参考文件保存的是图片参考数据，不是训练出的身份 LoRA；低分辨率提取会损失细节。
- 子弹时间已实际生成，其余九种特效提示数据尚未逐项验证触发强度。
- 原下载包的 RTX 超分工具没有适配当前 Linux ARM64 环境的发行包；本次以 H3 潜空间放大替代，不能保证与原工具相同。
- 原作者的三张大型工作流没有作为完整画布通过验收；当前交付的是拆分后的功能模板。
