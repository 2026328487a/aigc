# MiniMax H3 扩展工作流 · DGX

先看 [直白版使用说明](使用说明.md)：按界面模板逐项解释用途、素材、操作和参数，不熟悉的术语也有说明。

2026-10-31 将 `E:\Quark\dowmload\MiniMax H3` 的主要玩法拆成可独立运行的小图，接入 AIGC 工作台。扩展源码和 Python 环境独立，主模型与已有 DGX 权重共用。实际推理结果和效果限制见 [验收记录](validation.md)，可重复部署的路径与校验和见 [部署记录](deployment.md)。

双击项目的 `start.cmd`，或打开 [工作台](http://127.0.0.1:8766/)，选择 **MiniMax H3 · 视频**。模板的“一键打开”会启动环境并加载 ComfyUI 画布；上传输入素材后点击运行。成片自动下载、校验并放入 [本地作品库](http://127.0.0.1:8766/library)。

“禁用全部自定义节点”来自旧版工作台启动器中的 `--disable-all-custom-nodes`，不是你的画布设置。H3 扩展配置已启用所需插件；Qwen、Music 3 仍使用各自现有环境。

| 模板 | 输入和玩法 | 参数建议 |
|---|---|---|
| `h3-lightx` | 一张图片生成带声音的视频 | 默认 512×320、124 帧、4 步；首帧模型配首帧 LightX2V |
| `h3-continuation` | 同一人物的两段连续镜头 | 两段各 124 帧，保留 22 帧尾部约束，输出 226 帧，约 9.42 秒 |
| `h3-digital-human` | 人物图 + WAV，录音决定台词 | 自动按录音长度确定帧数，默认最多约 5.17 秒；成片保留输入音轨 |
| `h3-vocal-human` | 人物图 + 带伴奏录音，先分离人声再驱动视频 | 与数字人相同；成片使用分离后的人声 |
| `h3-character-swap` | 单人源视频 + 目标人物图片，迁移动作并替换外观 | 修改 `body_swap` 提示词；先用单人、无遮挡、动作较慢的视频 |
| `h3-head-swap` | 源视频 + 目标脸部图片，保留原身体和衣服 | 换头 LoRA 默认 0.8；侧脸、遮挡、多人镜头需单独调试 |
| `h3-anime` | 把真人视频重绘成动漫 | 动漫 LoRA 默认 0.8；可改画风，动作只是参考约束 |
| `h3-motion` | 人物图，尝试更自然的身体动作 | `mvmt` 提示词 + 动作 LoRA；建议与相同种子的普通参考图比较 |
| `h3-sharpen` | 输入视频，在保留动作的前提下重绘细节 | LMS LoRA 0.4、denoise 0.15；强度过高会改变脸与纹理 |
| `h3-latent-upscale` | 先生成，再用训练过的 3D 模型放大潜变量并二次采样 | 默认 1.5 倍并对齐 32；512×320 输出 768×480，音频沿用原潜变量 |
| `h3-face-refine` | 输入视频，跟踪一张脸、放大重绘并羽化回贴 | 默认 512×512 脸部画布、denoise 0.4；可调检测对象、裁剪范围和 blend |
| `h3-union-control` | 源视频，经 Canny 提取轮廓，控制构图与动作 | Union **2.0**，默认 strength 0.8；这是边缘控制示例，换深度／姿态图需要相应预处理 |
| `h3-effects` | 参考图 + 子弹时间 embedding 与运镜描述 | 提示词同时描述慢动作、冻结和环绕；其他特效可替换 embedding 名称 |
| `h3-refmod` | 把人物参考图保存为可复用的 `.safetensors` 参考素材，同时生成测试视频 | Full Reference 为 VAE 编码参考，不训练模型；默认参考短边 256，可提高分辨率 |
| `h3-refmod-reuse` | 上传之前保存的参考素材，无需重新编码图片 | 在加载节点点击“上传参考素材”；默认 strength 1.0 |

数字人的 `AIGCH3AudioWindow` 将音频截取到 `max_frames` 上限，按 H3 的 `5 + 17k` 帧网格向上对齐，末尾只补少量静音。默认上限 124 帧；长录音可先分段。音频遮罩约束生成过程，成片直接使用对应输入音轨，防止短录音之后出现额外台词。口型仍是 H3 生成结果，需要观看和听音验收。

视频输入在 `VHS_LoadVideo` 上传，默认按 24 fps 读取前 124 帧。人物图在 `LoadImage` 上传。数字人的音频在 `LoadAudio` 上传。服务器结束会话后清理这些素材，下一次需要重新上传。

RefMod 生成任务包含视频与参考文件两种结果。在作品库点击“查看全部结果”，下载 `.safetensors`，随后在复用模板的“上传参考素材”按钮中选择该文件。参考文件与工作流保存在本机，不依赖远端会话存活。它保存的是参考潜变量，不能等同于经过训练的人物 LoRA；低分辨率提取会损失细节。

可以把玩法串起来：先人物替换 → 把成片作为修脸模板的输入 → 再做细节增强。也可以先用 VoxCPM2 生成台词，再做数字人；或先用 Qwen 制作人物图，然后做动作、动漫和连续镜头。每个阶段的结果都能在作品库找回。

原三张大图中的 Get/Set、Easy 循环、手工 sigma 和多个增强支路被拆开，以便逐阶段检查。当前提供的是功能复现图，原作者的 299／358／290 节点画布没有作为整图通过验收。原下载文件保持原样。

多人物、多场景参考可在核心参考节点添加 `ref_image` 插槽，按 `<Picture 1>`、`<Picture 2>` 描述各自作用。外部声音用 `<Audio 1>`；视频用 `<Video 1>`。大图里缺失的社区特殊文本编码器以 DGX 已有的 NVFP4 AWQ 标准编码器替代，效果不能保证与作者样片相同。

DGX 已有 10 个 embedding，可在特效模板里替换名称并修改描述：

| 名称后缀（前缀为 `embedding:minimaxh3_`） | 尝试方向 |
|---|---|
| `bullet_time` | 慢动作、冻结、环绕 |
| `spiral_ascent` | 镜头螺旋上升 |
| `four_seasons` | 同场景季节变化 |
| `blooming_flowers` | 花朵绽放 |
| `fire_breath` | 奇幻喷火 |
| `storm_magic` | 风暴魔法 |
| `dark_magic` | 暗色魔法 |
| `art_is_explosion` | 风格化爆炸 |
| `kiss_camera` | 靠近镜头的动作 |
| `truman_show` | 特定场景与运镜风格 |

目前子弹时间模板做了实际推理，其他九种属于可尝试选项，尚未逐项验证视觉触发强度。

原 RTX 超分节点使用的 `nvidia-vfx` 当前没有 **Linux aarch64** wheel，因此不能在本机按原节点复现。默认使用 H3 3D latent upscale。GB10 的 CUDA 推理已实际运行，这个限制来自软件发行架构。

权重整理分两类：字节完全相同的副本可用 SHA256 确认；备用模型只是暂未使用，不等于冗余。现在没有删除权重。只读审计脚本可生成候选清单：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\audit_h3_weights.py "E:\Quark\dowmload\MiniMax H3"
```

输出为 `test-results/h3-extended/weight-audit.json`。确认保留位置、质量和回退需求之后再清理；同名但不同的 INT8 VAE 不按重复文件处理。
